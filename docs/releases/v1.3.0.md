# HDT Collection Exporter by Manacost v1.3.0

Release build for Hearthstone Deck Tracker.

## Highlights

- Adds derived `classStats` to full JSON exports.
- Adds `favoriteClass` based on the highest recorded game count.
- Adds `bestClassByWins` based on the highest recorded win count.
- Includes class stat changes in changes-only JSON exports.
- Bumps full export schema version to `3`.

## Data Notes

Class stats are derived from HDT `playerRecords`. For each non-zero `playerRecords.records[].data` value, the plugin treats the value as a hero DBF ID, resolves it through HearthDb, and aggregates wins/losses/ties by `CardClass`. `recordTypes[].type` keeps the raw numeric HDT/Hearthstone record type, usually the game mode bucket.

Raw `playerRecords` are still exported unchanged for sites that want their own interpretation.

## Install

1. Download `HdtCollectionExporter.dll`.
2. Copy it to `%AppData%\HearthstoneDeckTracker\Plugins`.
3. Fully restart Hearthstone Deck Tracker, including the tray icon.
4. Enable `Collection Exporter by Manacost` or `Экспорт коллекции от Manacost`.
