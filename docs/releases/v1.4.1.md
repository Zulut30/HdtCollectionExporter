# HDT Collection Exporter by Manacost v1.4.1

Patch release after a Windows and macOS audit.

## Fixes

- Validates baseline JSON more strictly before using it for changes export. Full export baselines must contain at least one card.
- Makes the HSTracker macOS adapter friendlier to HSTracker's Swift 5 project settings by avoiding newer optional-binding shorthand and key-path mapping syntax in user-facing paths.
- Prevents the macOS changes export from crashing on duplicate imported baseline keys by replacing trap-prone dictionary construction with explicit lookup builders.
- Updates the macOS menu state after saving the current collection as a baseline.

## Compatibility Notes

- Windows: Hearthstone Deck Tracker plugin DLL, built for x86/.NET Framework.
- macOS: source-level HSTracker adapter. HSTracker does not expose the same drop-in plugin mechanism as HDT, so the Swift files must be added to an HSTracker build target.
- Export schema remains version `3`; no website parser changes are required if it already supports v1.4.0 exports.
