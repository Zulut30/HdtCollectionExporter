# HDT Collection Exporter by Manacost v1.2.1

Release build for Hearthstone Deck Tracker.

## Highlights

- Manacost-branded export window with embedded logo.
- Full collection export to JSON and CSV.
- Changes-only export to JSON and CSV.
- Shared baseline for English and Russian plugin entries.
- Baseline tools: set current, import full JSON, clear baseline.
- Local-only export: no data is sent to external services.

## Install

1. Download `HdtCollectionExporter.dll`.
2. Copy it to `%AppData%\HearthstoneDeckTracker\Plugins`.
3. Fully restart Hearthstone Deck Tracker, including the tray icon.
4. Enable `Collection Exporter by Manacost` or `Экспорт коллекции от Manacost`.
