# HDT Collection Exporter by Manacost v1.4.0

Release build for Hearthstone Deck Tracker plus source-level macOS adapter for HSTracker.

## Highlights

- Adds `macos/HSTrackerManacostExporter`, a Swift adapter for HearthSim/HSTracker.
- HSTracker adapter exports the same JSON schema version `3` and UTF-8 CSV format.
- Adds HSTracker full export and changes-only export logic with a local baseline.
- Adds HSTracker menu controller with export buttons, output folder selection, and include toggles.
- Adds English and Russian HSTracker macOS documentation.
- Keeps the Windows HDT plugin behavior unchanged.

## HSTracker Notes

HSTracker does not currently expose a drop-in plugin loader like HDT. The Swift adapter must be added to an HSTracker fork or custom build. It uses HSTracker's own `CollectionHelpers.hearthstone.getCollection()` data path and does not perform manual memory reading or network uploads.

## Install

Windows HDT users:

1. Download `HdtCollectionExporter.dll`.
2. Copy it to `%AppData%\HearthstoneDeckTracker\Plugins`.
3. Fully restart Hearthstone Deck Tracker, including the tray icon.
4. Enable `Collection Exporter by Manacost` or `Экспорт коллекции от Manacost`.

macOS HSTracker developers:

1. Read `docs/HSTRACKER_MACOS.en.md` or `docs/HSTRACKER_MACOS.ru.md`.
2. Copy `macos/HSTrackerManacostExporter/*.swift` into an HSTracker source tree.
3. Add the files to the HSTracker Xcode target.
4. Install `ManacostCollectionExportMenuController` from `AppDelegate.buildMenu()`.
